# Scope and distribution

Research checked 15 November 2026:

- https://www.markup.io/blog/how-to-annotate-an-image/ — image annotations and resolving feedback.
- https://educate.ceros.com/en/articles/12454641-leaving-feedback-on-a-markup — pin-based feedback.
- https://educate.ceros.com/en/articles/12454599-actioning-feedback-on-a-markup — actioning and resolving feedback.

Our implemented scope is raster image upload, normalized-coordinate comments, owner resolution/reopening, revocable board access and export. These are specific overlapping workflows, not a claim of complete MarkUp.io equivalence or current G2/AppSumo ranking.

Provisional name: Review Dots. GitHub `review-dots in:name` search returned no exact-name match in the first results; broader brand/domain checks remain. The name is not claimed to be legally cleared. Pin Folio was rejected because an exact GitHub name already exists.

Distribution path: publish a reproducible agency design-review example using the bundled synthetic poster. Demonstrate reviewer pin → owner resolution → exported JSON and image. Package the local workflow first; complete an HTTPS/container installation recipe before offering remote-client sharing. Once public and release-ready, evaluate a factual self-hosted image-review directory listing or a useful integration with an agency's static preview workflow against that project's actual contribution policy. No external listing, endorsement, submission or launch post has occurred.

Remaining launch gates: six languages, public HTTPS review when hosting is authorized, broader name review and native-speaker review. No publication authorized for this new product yet.
